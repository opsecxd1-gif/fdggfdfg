    railway open                                # Dashboard im Browser öffnen

6b. DISCORD BOT: /dev (Selbst-Entwicklung, nur Owner)
========================================
- Befehl: /dev <task>  -> Bot liest/schreibt eigene Dateien, prüft Syntax
  (python -m py_compile bot.py) und pusht automatisch nach GitHub.
  Railway deployt dann automatisch.
- Nur der Bot-Owner (App-Owner via application_info) darf /dev nutzen.
- Tools des Agents: read_file, write_file, run_command.
- Blockliste: rm -rf /, shutdown, reboot, mkfs, dd, git push --force, ...
- Push aus dem Container funktioniert OHNE Token (Railway's Origin hat
  Schreibrechte, bewiesen durch [AutoSave] Data backup pushed).
  Falls nötig, zusätzlich Env-Var GITHUB_TOKEN setzen:
  GitHub -> Settings -> Developer settings -> Tokens (classic) -> "repo".
- git + ffmpeg sind im Container via railpack.json installiert
  (deploy.aptPackages: ["...", "git", "ffmpeg"]).
- WICHTIG: nixpacks.toml wird von Railways neuem Builder (Railpack)
  IGNORIERT! Pakete über railpack.json oder Env-Vars
  RAILPACK_DEPLOY_APT_PACKAGES/RAILPACK_BUILD_APT_PACKAGES setzen.
