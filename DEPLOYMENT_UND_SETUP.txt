2. WIE MAN ÄNDERUNGEN ONLINE BRINGT
=====================================

Änderungen werden NICHT automatisch hochgeladen!
Nach jedem Code-Änderung im Terminal:

  cd I:\discordgifbot
  git add .
  git commit -m "Beschreibung"
  git push

Railway deployed dann automatisch neu (30-60 Sekunden).

3. BOT-COMMANDS (nur mit 976-Rolle)
=====================================

Alle Commands funktionieren NUR für User mit der "976" Rolle.
Andere User können KEINE Commands ausführen.

Commands:
  /add         - GIF/Media-Links hinzufügen
  /load        - .txt Datei mit Links hochladen
  /start       - GIF-Senden starten
  /cont        - GIF-Senden fortsetzen
  /stop        - GIF-Senden stoppen
  /next        - Nächste GIFs senden
  /status      - Aktuellen Stand anzeigen
  /clear       - Liste löschen
  /embedvideos - Video-Embed Toggle
  /size        - Anzahl pro Nachricht setzen
  /list        - Erste/letzte 5 Links zeigen
  /pos         - Position manuell setzen
  /import      - Bis zu 10 .txt Dateien (neue Channels)
  /import2     - Bis zu 10 .txt Dateien (diesen Channel)
  /filtermode  - Erweiterter Media-Filter
  /nofiltermode - Kein Filter
  /clearchannels - Alle Bot-Channels löschen
  /permsync    - Permissions synchronisieren
  /hoistall    - Alle Rollen "getrennt anzeigen"
  /reactionrole - Reaction-Roles verwalten (add/remove/list/clear)
  /reactionsetup - Webhook+Embed+Button für eine Rolle
  /masssetup   - ALLE User-Rollen als Buttons (mehrere Seiten)
  /tiktokmode  - TikTok Auto-Download Service wählen
  /tiktoktoggle - TikTok Auto-Download ein/ausschalten
  /tiktokstatus - TikTok Auto-Download Status anzeigen
  /setavatar    - Bot-Profilbild ändern (Bild reinziehen)
  /setbanner    - Bot-Bannerbild ändern (Bild reinziehen)
  /level       - Zeigt dein aktuelles Level und XP an
  /leaderboard - Zeigt das Leaderboard an
  /setlevelchannel - Setzt den Channel für Level-Up Nachrichten
  /setleaderboard - Setzt den Channel für das Live-Leaderboard
  /levelimage  - Setzt ein Bild für einen Levelaufstieg
  /noxpchannel - Toggle: Kein XP in diesem Channel
  /resetlevels - Setzt alle Level-Daten zurück
  /setlevel    - Setzt das Level eines Users manuell
  /ticketsetup - Ticket-System einrichten
  /close       - Ticket schliessen
  /ticketadd   - User zum Ticket hinzufuegen
  /ticketremove - User aus Ticket entfernen
  /transcript  - Transkript generieren
  
  =====================================
  AUTO-MEMES SYSTEM (NEU)
  =====================================
  /memessetup  - Auto-Memes Channel einrichten (reddit/imgur/liste/gemischt)
  /memesinterval - Interval ändern (1-48 Stunden)
  /memestoggle - Auto-Memes ein/ausschalten
  /memesquelle - Memes-Quelle ändern
  /memessubreddit - Reddit Subreddit setzen
  /memesskip   - Nächstes Memé manuell senden
  /memestest   - Testet die Memes-Quelle
  /memesstatus - Zeigt Auto-Memes Status
  /memesadd    - Meme-Links zur Liste hinzufügen
  /memesload   - Memes aus .txt Datei laden
  
  =====================================
  FRAGE DES TAGES (NEU)
  =====================================
  /fragesetup  - Frage des Tages einrichten
  /frageinterval - Interval ändern (1-48 Stunden)
  /fragetoggle - Frage des Tages ein/ausschalten
  /fragestatus - Zeigt Frage-des-Tages Status
  /frageadd    - Eigene Frage hinzufügen
  /fragetest   - Testet eine Frage manuell
  /frageresults - Zeigt Ergebnisse einer Frage

6. PROBLEME & FIXES
=====================================

Problem: "DISCORD_TOKEN nicht gesetzt"
  → In Railway Variables Tab den Token eintragen

Problem: Buttons funktionieren nicht
  → Eigener Webhook "Reaction Roles" wird erstellt
  → Carl-bot Webhook NICHT benutzen (gehört denen)

Problem: Git Push fehler wegen Tokens
  → Token aus sync.py und list_roles.py entfernt
  → .env Datei wird nicht hochgeladen (.gitignore)
